# 🌐 TSLAN.fr

[!\[Site Officiel](https://img.shields.io/badge/Site\_Officiel-tslan.fr-blue?style=for-the-badge)](https://tslan.fr)
[!\[License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)

> Plateforme web officielle de la \*\*TSLAN\*\*, événement gaming organisé par l'association \*\*GOTS\*\* (Games On The Stage).

\---

## Fonctionnalités

* **Gestion des événements :** Actualités de l'événement, redirections d'inscriptions, planning, informations sur les tournois et archives.
* **Performance \& SEO :** Interface fluide et optimisée pour le référencement naturel.
* **Responsive Design :** Ergonomie adaptée à tous les types d'écrans (Desktop, Tablette, Mobile).

\---

## Stack Technique

* **Frontend :** HTML5, CSS3, JavaScript
* **Backend :** Node.js
* **Hébergement :** Auto-hébergé sur serveur personnel, sécurisé et accessible via le réseau Cloudflare
